Printing isn't available here
This logbook is currently open as the installed Home Screen app. iOS doesn't let apps installed this way open the print/PDF sheet at all — it's a limitation of iOS itself, not something this app can turn on. Printing only works when the same page is open as a normal tab in Safari.
To print or save as PDF: open Safari, go to this address, then use the Share button → Print (or Save to Files as PDF) from there.
Before you print
Your browser adds its own URL / date / page-number strip to every printed page on top of this logbook's margins — that's the extra text at the very top and bottom of the pages. This is a browser print-dialog setting; the app can't turn it off for you, but it only needs fixing once.
In the print dialog that's about to open:
• Chrome / Edge: click "More settings", then turn off "Headers and footers".
• Safari (Mac): in the print panel, uncheck "Show details" → uncheck the header/footer option, or use the "Show Print Details" checkbox to reveal it.
• iPhone/iPad AirPrint: this option isn't available on iOS — the strip may still appear there.
